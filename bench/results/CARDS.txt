DELEGATION IS PRICED BY TASK WIDTH
sub-agent windows rescue dense payloads — only when the work splits
──────────────────────────────────────────────────────────────────────────

  Token change when the agent is allowed to delegate to sub-agents,
  by how WIDE the question is:

  task                         baseline  Pathfinder   CodeGraph
  survey 61 route files             -28%        -61%        -68%
  trace 1 auth chain                +16%        +58%        -65%
  audit 1 pattern                  +126%         -2%        +38%
  enumerate 1 API                   +85%        +71%       +100%
  trace 1 call chain               +167%       +178%       +141%

  Delegation only pays on the WIDE task — and there it pays most
  for the graph. On narrow questions it is pure overhead.

  This is why a multi-agent audit and a single-agent lookup
  report opposite results for the same tool.
